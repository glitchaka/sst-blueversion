SST — Configuración portable: config / sst-config / sst-path

Backend nativo:
  sst-config

Ruta de configuración:
  sst-config
  sst-config path

Editar:
  sst-config edit

Fondos — listar:
  sst-config bg
  sst-config bg list

Desactivar:
  sst-config bg off
  sst-config bg none          alias

Fondo fijo:
  sst-config bg NOMBRE
  sst-config bg NUMERO

NOMBRE puede coincidir con nombre de archivo o stem. NUMERO corresponde al listado actual.

Carrusel:
  sst-config bg carrousel
  sst-config bg carousel      alias ortográfico
  sst-config bg carrousel MINUTOS

MINUTOS:
  entero 1..60
  default 3

Rotación manual:
  sst-config bg next

Formatos reconocidos por la carpeta bg según SST:
  PNG, JPG, JPEG, WebP, BMP, GIF, ICO, TIFF

Variables gestionadas:
  SST_BACKGROUND_MODE
  SST_BACKGROUND_IMAGE
  SST_BACKGROUND_CAROUSEL_MINUTES

Reload:
  config reload               recarga el entorno desde la interfaz pública. El backend directo sst-config reload no recarga la shell.

Rutas:
  sst-path PATH

`sst-path` traduce/resuelve rutas estilo /c/... contra el directorio de trabajo al modelo Windows.

`config` es la interfaz pública incorporada de SST; `sst-config` es el backend explícito. El intérprete reenvía las operaciones de apariencia al backend y conserva path y reload en la shell.

### Paletas de fuentes

`config palette list` muestra las opciones. `config palette sunset`, `config palette golden` y `config palette gruvbox` seleccionan la paleta persistente en `SST_FONT_PALETTE`. El fondo y el logotipo no cambian. Los colores de estado conservan su distinción semántica.

Para listar las paletas: config palette list
Para consultar la activa: config palette
Autocompletado: config palette <TAB>

Las paletas también se aplican a los elementos gráficos de `demo graficos`. Cambia el esquema con `config palette sunset`, `config palette golden` o `config palette gruvbox` antes de entrar al catálogo. No es necesario reiniciar SST.
