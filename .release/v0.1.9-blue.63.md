# Shell Shock Tool 0.1.9-blue.63

## Tema global Gruvbox Dark
- Interfaz Slint, isla de estado, controles, contornos, barras de transferencia, cursor, selección y paleta ANSI con colores Gruvbox Dark.
- Fondo predeterminado #282828, texto #ebdbb2; migración conservadora desde los valores azulados originales en instalaciones existentes, sin sobrescribir preferencias personalizadas.
- Informes normales y monitores TUI: blanco/gris para información, rojo para errores críticos, naranja/amarillo para advertencias, verde para funcionamiento correcto y azul exclusivamente para estados explícitamente óptimos.
- Cabeceras de informes y detección de secciones usan el mismo marcador RGB neutral: los contornos vectoriales nativos vuelven a aparecer sin depender del marcador celeste obsoleto.
- Se mantiene el logo, la lógica de privilegios, el funcionamiento de comandos y las salidas estructuradas CSV/JSON.

## Correcciones incluidas
- Conserva los cambios de blue.61 para el texto semántico, etiqueta USUARIO y streaming de ping/procesos externos.
