# Shell Shock Tool 0.1.9-blue.61

## Presentación general de texto SST
- Los comandos nativos comparten un mismo renderizador para informes y ayudas; los textos estructurados externos utilizan el mismo criterio semántico.
- Se eliminó el exceso de celeste en cabeceras, nombres de comandos, descripciones y monitores. El contenido ordinario utiliza blanco y gris.
- Se respetan cuatro grados de estado: rojo crítico/error, amarillo-naranja advertencia, verde funcionamiento correcto y azul únicamente para estados explícitamente perfectos/óptimos.
- Los valores solo reciben un color de estado cuando corresponden a un campo de estado real. La descripción de `sys drivers --devices` nunca puede colorearse como conexión activa.
- Las cabeceras vectoriales de Slint son transparentes y miden el ancho del título, sin invadir otras líneas ni tapar el fondo o el logo.
- El modo alternativo de `net monitor` y `net traffic --watch` también utiliza títulos y marcos neutros.
- Se mantiene intacta la salida de datos para CSV, JSON, pipelines, redirecciones, scripts y texto con ANSI existente.

## Salida nativa en tiempo real
- `ping` y otros procesos externos directos muestran líneas a medida que el proceso las escribe, en lugar de esperar a su finalización.
- Se conservan los retornos de carro y secuencias CRLF de Windows, la salida binaria y el control de interrupción Ctrl+C.
- Pruebas: la primera respuesta se recibe antes de producirse la segunda; las rutas capturadas siguen entregando datos completos.

## Privilegios
- Se revierte la etiqueta `LIMITADO` para el token de administrador filtrado: la isla muestra `USUARIO`, como antes.
- No se cambian los privilegios reales, las APIs de Windows ni el comportamiento de `sudo`.
