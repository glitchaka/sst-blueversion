# Shell Shock Tool 0.1.9-blue.0

- La configuración de apariencia incorpora `SST_FONT_COLOR='#DFE8EF'` para cambiar el color base del texto de la terminal y aplicarlo con `config reload`, sin alterar los colores ANSI explícitos de comandos, avisos o neofetch.
- El logo ANSI de neofetch restaura el azul eléctrico original en los bloques de iluminación del logotipo SST, manteniendo intactos el cuerpo gris y las sombras azules oscuras.
- Mantiene los fixes ya incorporados en 0.1.8-blue.4, incluido el diagnóstico moderno de Microsoft 365 Click-to-Run y el updater automático.
