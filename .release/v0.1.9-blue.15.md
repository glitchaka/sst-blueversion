# Shell Shock Tool 0.1.9-blue.15

Correcciones de compatibilidad del intérprete Nwash con Bash, acumuladas desde 0.1.9-blue.11:

- blue.12: diferencia entre el salto de línea y el separador `;` para aceptar expresiones `[[ ... ]]` multilínea.
- blue.13: conserva como un único operando las expresiones regulares ERE de `[[ valor =~ patron ]]` (paréntesis, cuantificadores, alternancias).
- blue.14: acepta opciones cortas agrupadas y argumentos adjuntos en `read`, por ejemplo `read -rsn1 opcion` y `read -p"Nombre: " nombre`.
- blue.15: soporta clases de caracteres POSIX en los patrones condicionales, como `[[:space:]]` y `[[:digit:]]`.

Incluye pruebas de regresión para las construcciones corregidas. Estas mejoras no implican todavía conformidad completa de Nwash con GNU Bash 5.3; las diferencias no atribuibles a Windows siguen siendo defectos pendientes.
