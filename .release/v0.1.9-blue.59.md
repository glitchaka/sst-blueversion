# Shell Shock Tool 0.1.9-blue.59

## Presentación compartida para comandos SST
- Las cabeceras de ayudas e informes SST se identifican semánticamente al generar el texto y la ventana nativa dibuja sobre ellas bandas vectoriales transparentes con bordes redondeados y acento cian.
- La salida de comandos administrativos deja de depender de listas de texto plano sin jerarquía. Los comandos en ayudas se distinguen de sus descripciones y los encabezados de tablas y secciones tienen un tratamiento coherente.
- Corrige el falso color de estado en frases como «sys drivers --devices ... dispositivos PnP conectados»: las descripciones no se interpretan como dispositivos conectados.
- El diseño compartido cubre herramientas nativas SST; conserva el ANSI previo, `fetch`, tuberías, redirecciones, CSV y JSON.
- Los encabezados gráficos se recalculan según las filas visibles del terminal; no se incrustan cajas ASCII ni fondos opacos en el logo.

## Progreso de descarga dentro de la consola
- Retira completamente el componente `DownloadCard` flotante.
- El comando reserva líneas en el terminal para su propio estado de transferencia; Slint dibuja una barra nativa redondeada **exactamente en esas líneas**, sin fondo de tarjeta, popup, controles adicionales ni ventana independiente.
- Etiqueta, resultado de descarga y finalización aparecen en el mismo flujo de salida. Porcentaje, velocidad y ETA se calculan con bytes reales y no se inventan cuando no hay tamaño remoto.
- La consola externa mantiene el modo alternativo a través de libcaca.
- No se modifica la isla, el compositor general, el logo ni las imágenes de fondo.

## Recuperación del ejecutable ante bloqueo de Windows
- Si Windows deniega el arranque del ejecutable recién actualizado, el actualizador restaura automáticamente el SST anterior desde `sst.exe.old`.
- La instalación solo se registra como aplicada después de que Windows acepta iniciar el nuevo ejecutable. Si falla, se registra el error para diagnóstico.
- Una prueba de Windows inyecta un acceso denegado al iniciar el nuevo SST y comprueba la restauración del ejecutable anterior.
