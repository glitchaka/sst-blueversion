# SST 0.1.11-blue.1 — Netcheck: diagnóstico y aislamiento de fallas de red

- Se incorpora el comando nativo `netcheck` para investigar fallas de conectividad desde SST, con conclusiones basadas en evidencias y sin reparaciones automáticas.
- Revisa interfaces físicas Ethernet y Wi-Fi, direcciones APIPA, ruta IPv4 predeterminada, respuesta ICMP de puerta de enlace, resolución DNS, respuesta ICMP del destino y conexión TCP al servicio indicado.
- Informa estados, limitaciones y acciones de investigación en orden. Una ausencia de respuesta ICMP no se interpreta automáticamente como una falla de enlace o de Internet.
- Uso: `netcheck`, `netcheck HOST` o `netcheck HOST --port PUERTO`.
- Integra ayuda con `help netcheck`, `netcheck --help` y ficha de `guide`, incluyendo compatibilidad con índices de guía no actualizados.
- Pruebas Rust para clasificación de APIPA, falta de enlace y ruta predeterminada, más prueba funcional Windows obligatoria para publicación.
- Conserva los cambios anteriores de descripción de paquetes Arch en guide.
