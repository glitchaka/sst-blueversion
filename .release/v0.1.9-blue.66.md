# Shell Shock Tool 0.1.9-blue.66

## Corrección crítica: SST no abre si el controlador OpenGL no está disponible
- Se elimina el requisito de OpenGL 2.0 del inicio de SST Blueversion.
- La ventana principal se renderiza con el backend nativo Winit + Slint Software, seleccionado expresamente antes de crear la ventana.
- El renderizador FemtoVG/OpenGL deja de compilarse en SST. Se evita el fallo `Winit backend failed to find a suitable renderer: The FemtoVG renderer requires an OpenGL 2.0 driver`.
- Se mantiene la ventana SST sin decoraciones, la superficie de terminal, el tema Gruvbox Dark, el indicador de privilegios y los comandos; sin CMD ni PowerShell como interfaz.
- Se incorpora una prueba de arranque en Windows sin aceleración gráfica, obligatoria para compilaciones y para la publicación.
- Motivo: Slint documenta que el fallback automático a software puede fallar demasiado tarde para recuperar la ventana en Windows (slint-ui/slint#8708). Por eso el renderer software se selecciona explícitamente.

## Verificación
- La compilación Windows, el arranque con software y las pruebas de regresión bloquean la publicación ante un error.
