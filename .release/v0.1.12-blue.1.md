# SST 0.1.12-blue.1 — Netprobe, Keygen, Neofetch y Active Directory

Nueva herramienta nativa ampliada:

- `netprobe` ejecuta informe de conectividad, velocidad observada, pérdida ICMP y tráfico ETW por proceso.
- `netprobe loss HOST --count N --interval MS` calcula pérdida, RTT, variación de latencia y rachas de fallo, sin confundir errores locales de la API con pérdida de paquetes.
- `netprobe stability HOST --seconds N` mide estabilidad a lo largo del tiempo; `--tcp PUERTO` evalúa disponibilidad de conexión TCP, sin afirmar medir pérdida IP.
- `netprobe speed --seconds N` realiza mediciones HTTPS de descarga y subida mediante WinHTTP e informa además del tráfico real de las interfaces; `--passive` mide solo tráfico del adaptador.
- `netprobe speed --download https://SERVIDOR/archivo.bin --seconds N --max-mib N` hace descarga HTTPS real mediante WinHTTP a un destino explícito, sin binarios externos y con límites de tiempo/volumen. No equivale a prueba de subida.
- `netprobe traffic --seconds N` usa ETW y tablas de conexiones Windows para correlacionar bytes enviados/recibidos, PID, proceso, puertos/destinos y servicios Windows en el mismo proceso; avisa al detectar servicios que comparten PID.
- `netprobe packets --seconds N` muestra eventos de red ETW individuales: sentido, tamaño, PID y clase. No promete capturar payload ni descifrar TLS.
- `netprobe capture --interface IPV4_LOCAL --seconds N` utiliza Winsock SIO_RCVALL para capturar cabeceras IPv4 reales, puertos y flags, con correlación probable al PID y servicios a partir de la instantánea de conexiones. Requiere Administrador y NIC compatible; el parámetro optativo `--payload-bytes N` muestra hasta 64 bytes de contenido hexadecimal y ASCII imprimible, sin descifrar TLS y sin capturar tráfico de otros equipos.
- Diagnóstico sin cambios automáticos de DNS, DHCP, VLAN, firewall o NAC.
- Regresiones Windows y pruebas de unidades para estadísticas, límites y URL HTTPS, con controles obligatorios de publicación.

## SST y seguridad

- `netprobe` sustituye a `netcheck`/`netdiag` como único comando público; no conserva aliases de esos nombres.
- `keygen` utiliza animación con velocidad, rotación, inercia angular, impactos, rebotes y proyección de profundidad.
- `keygen` incorpora los dos MP3 originales validados por SHA-256 en el instalador y en la distribución portable; el usuario no debe copiarlos manualmente.
- `neofetch` toma la paleta de colores del archivo `assets/sst-icon.png` y elimina acentos externos al icono.
- `unban` solicita una cuenta administrativa de dominio explícita, sin `sudo`, y utiliza LDAP nativo con autenticación SSPI Negotiate, firma y cifrado.
- El actualizador se distribuye junto a SST y consulta el canal blue sólo después de una publicación verificada.
