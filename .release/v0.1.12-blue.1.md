# SST 0.1.12-blue.1 — Netcheck: diagnóstico de red con mediciones reales

Nueva herramienta nativa ampliada:

- `netcheck` ejecuta informe de conectividad, velocidad observada, pérdida ICMP y tráfico ETW por proceso.
- `netcheck loss HOST --count N --interval MS` calcula pérdida, RTT, variación de latencia y rachas de fallo, sin confundir errores locales de la API con pérdida de paquetes.
- `netcheck stability HOST --seconds N` mide estabilidad a lo largo del tiempo; `--tcp PUERTO` evalúa disponibilidad de conexión TCP, sin afirmar medir pérdida IP.
- `netcheck speed --seconds N` mide tráfico actual por interfaz Ethernet/Wi-Fi física con IP Helper, además de enlace negociado, errores y descartes.
- `netcheck speed --download https://SERVIDOR/archivo.bin --seconds N --max-mib N` hace descarga HTTPS real mediante WinHTTP a un destino explícito, sin binarios externos y con límites de tiempo/volumen. No equivale a prueba de subida.
- `netcheck traffic --seconds N` usa ETW y tablas de conexiones Windows para correlacionar bytes enviados/recibidos, PID, proceso, puertos/destinos y servicios Windows en el mismo proceso; avisa al detectar servicios que comparten PID.
- `netcheck packets --seconds N` muestra eventos de red ETW individuales: sentido, tamaño, PID y clase. No promete capturar payload ni descifrar TLS; la captura real de contenido requiere un controlador apropiado y autorización.
- Diagnóstico sin cambios automáticos de DNS, DHCP, VLAN, firewall o NAC.
- Regresiones Windows y pruebas de unidades para estadísticas, límites y URL HTTPS, con controles obligatorios de publicación.
