# Shell Shock Tool 0.1.9-blue.53

## NOTSH: LAN, WLAN y formatos de salida
- Se aceptan ambas sintaxis `notsh show lan interfaces` y `notsh lan show interfaces`, además de las equivalentes WLAN.
- `notsh interfaces --csv` y las variantes LAN/WLAN exportan columnas CSV reales desde las APIs nativas de Windows; no convierten en CSV el texto decorado del terminal.
- La consulta LAN limita el inventario a adaptadores Ethernet físicos; el inventario general puede incluir filtros y adaptadores virtuales y lo identifica explícitamente.
- Se preservan las exportaciones CSV previas de `scan`, `traffic`, `presence` y `usage`.

## Presentación gráfica
- Se elimina el marco de guiones del encabezado de informes.
- El compositor nativo Slint dibuja el fondo redondeado del encabezado como píxeles reales. El flujo de texto permanece limpio para automatización, redirecciones y scripts.
- Se conserva libcaca-rs para componer texto de encabezados; los marcos ya no se simulan con caracteres ASCII.

- Si el servicio WLAN no está disponible, `--csv` conserva el encabezado CSV y comunica el error de Windows por stderr y código de salida, sin inventar interfaces.

## Verificación
- Pruebas de rutas LAN/WLAN y exportaciones CSV de Windows.
- Validación mediante compilación, pruebas Rust, comprobación de integración NOTSH, prueba negra de terminal y auditoría antes de publicar los binarios.
