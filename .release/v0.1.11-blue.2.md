# SST 0.1.11-blue.2 — Ajustes del diagnóstico de red

- Netcheck incorpora la consulta nativa de Wired AutoConfig mediante la API Dot3 de Windows, distinguiendo un perfil 802.1X configurado de una autorización NAC realmente demostrada.
- La clasificación de DNS evita declarar caída de red cuando únicamente falla el nombre de destino.
- Las conclusiones ordenan primero los hallazgos críticos y luego las advertencias.
- Conserva todos los diagnósticos de SST 0.1.11-blue.1: enlace físico, APIPA/DHCP, puerta de enlace, DNS, ICMP y TCP.
- No cambia la configuración de la red ni expone credenciales.
