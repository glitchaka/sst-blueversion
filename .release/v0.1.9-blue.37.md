# Shell Shock Tool 0.1.9-blue.37

## Presentación de informes
- Se integra libcaca-rs para los encabezados de informes nativos dentro de la terminal SST.
- Los valores de diagnóstico se mantienen legibles, con etiquetas diferenciadas y colores específicos para errores, advertencias y estados operativos.
- Los formatos JSON/CSV, las redirecciones, las tuberías y los scripts no reciben decoración de pantalla.

## NOTSH con API nativas
- Se retira el antiguo adaptador que delegaba en netsh.exe.
- El contexto WLAN consulta redes, conexiones y perfiles mediante Windows WLAN API.
- Los contextos IPv4 e IPv6 usan las tablas de Windows IP Helper.
- El contexto LAN separa la condición física del Ethernet, la presencia de perfiles Dot3 y el estado del servicio Wired AutoConfig, sin presentar enlace o IP como prueba de autenticación NAC.
- Se añade la consulta de proxy WinHTTP predeterminado mediante WinHttpGetDefaultProxyConfiguration; no ejecuta PowerShell, CMD ni Netsh.
- Las rutas no implementadas notifican expresamente el límite en vez de devolver datos genéricos o engañosos.

## Seguridad y validación
- El paquete SQLite integrado se actualiza mediante rusqlite 0.41.1 y libsqlite3-sys 0.39.1.
- Se incorporan pruebas en un runner real de Windows para los comandos nativos LAN, WLAN, IPv4 e IPv6, con límites de ejecución y comprobación de retorno al intérprete.
- Se conserva el actualizador independiente, que sólo instala por autorización explícita.

## Limitaciones actuales
NOTSH no tiene todavía equivalencia total con todos los comandos históricos de Netsh. Faltan operaciones avanzadas de administración de firewall, Winsock, HTTP, algunos ajustes de Wired AutoConfig, trazas de sistema y opciones de modificación. La detección de un perfil configurado no acredita autorización efectiva 802.1X/NAC.
