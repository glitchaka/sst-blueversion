# Shell Shock Tool 0.1.9-blue.70

## Seguridad de credenciales (domain / autologon)

- `sys domain join/leave` conserva la captura por ventana de credenciales protegida, siempre después de UAC si se requiere.
- `sys autologon` ya no entrega contraseñas a Sysinternals por argumentos. Configura el inicio automático mediante APIs nativas Windows: CredUI para la captura, LsaStorePrivateData para el secreto LSA, y valores Winlogon no secretos para el usuario, dominio y habilitación.
- `sys autologon disable` desactiva AutoAdminLogon y elimina la contraseña del registro y el secreto LSA, sin solicitar un secreto nuevo.
- El mecanismo bloquea credenciales en argumentos tanto antes de ejecutar la shell (incluidos modos verbose) como después de expandir variables y alias, antes de DEBUG, BASH_COMMAND o xtrace.
- El editor integrado bloquea caracteres después del modificador `-p` en operaciones de dominio y Autologon.
- El historial persistente y la vista integrada omiten estas operaciones; se depuran automáticamente líneas antiguas con `-p` de ambos comandos.
- CI incluye pruebas negativas con contraseñas ficticias, sin realizar uniones a dominio ni configurar inicio automático en máquinas de prueba.

### Sintaxis actual

```
sys domain join -d DOMINIO -u CUENTA [-ou RUTA_OU] -p
sys domain leave -u CUENTA -p
sys autologon enable -u CUENTA -d DOMINIO -p
sys autologon disable
```

`-p` **nunca** recibe una contraseña en texto claro; SST la solicita en CredUI.

### Advertencias

Autologon reduce la seguridad física del dispositivo aunque el secreto se almacene cifrado en LSA. Un administrador o atacante con privilegios elevados puede acceder a secretos LSA. La funcionalidad debe emplear cuentas de privilegios mínimos y respetar las políticas del equipo.

Las pruebas automatizadas no pueden demostrar una autenticación real en Active Directory ni un reinicio con inicio automático; esas verificaciones requieren una máquina administrada, cuenta de prueba y autorización. Cualquier contraseña que se haya introducido con sintaxis antigua debe rotarse.
