# Shell Shock Tool 0.1.9-blue.70

## Seguridad y correcciones

- Domain solicita contraseñas mediante CredUI, después de UAC cuando corresponde, sin incluir secretos en argumentos.
- Autologon usa APIs nativas de Windows para capturar credenciales con CredUI y almacenarlas como secreto LSA.
- Autologon disable apaga AutoAdminLogon y elimina las credenciales de inicio automático almacenadas.
- SST rechaza contraseñas introducidas después de -p, incluso tras expansión de comandos, sin registrarlas en el historial ni en xtrace.
- La consola bloquea escritura y autocompletado al llegar al modificador protegido -p.
- Fetch, neofetch y fastfetch muestran SST como texto real y compacto, no como una matriz de píxeles ni letras gigantes.
- El arranque gráfico utiliza el renderizador de software de Slint, sin exigir OpenGL ni FemtoVG.
- Las pruebas de Windows comprueban el rechazo de credenciales en línea, el renderizado y los flujos de actualización.

## Uso seguro

```text
sys domain join -d DOMINIO -u CUENTA -p
sys domain leave -u CUENTA -p
sys autologon enable -u CUENTA -d DOMINIO -p
sys autologon disable
fetch
fetch --full
```

La contraseña se introduce exclusivamente en el diálogo protegido de Windows. Nunca se escribe después de -p.

## Limitaciones

Autologon reduce la seguridad física del dispositivo y un administrador con privilegios altos puede acceder a secretos LSA. Utiliza cuentas de privilegios mínimos.

Las pruebas automáticas de Windows no sustituyen una operación real de dominio ni un reinicio para verificar Autologon; esas pruebas necesitan una máquina de laboratorio autorizada.
