# Shell Shock Tool 0.1.9-blue.62

## Gruvbox Dark — apariencia global
- Nueva paleta Gruvbox Dark para la superficie Slint de SST: isla superior, contornos de cabeceras y paneles, botones, barra integrada de transferencia, texto, cursor y selección.
- Los 16 colores ANSI de la terminal usan la paleta Gruvbox Dark; se mantienen los códigos RGB explícitos que aportan significado a los informes.
- Los monitores interactivos utilizan tonos Gruvbox: blanco/gris para texto ordinario, rojo para errores y condiciones críticas, amarillo/naranja para advertencias, verde para funcionamiento correcto. Azul solo para estados inequívocamente óptimos.
- Los valores predeterminados de configuración pasan a fondo #282828 y texto #ebdbb2.
- Las instalaciones existentes migran automáticamente únicamente los anteriores valores predeterminados #111629 y #DFE8EF, sin sustituir colores de fondo o texto personalizados.
- No se altera el logo SST ni la lógica de permisos, red, comandos, CSV/JSON o procesos interactivos.
