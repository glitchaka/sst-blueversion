# SST 0.1.11-blue.3 — CSV universal con redirecciones

- Corrige la aplicación de `--csv` en el intérprete Nwash, en lugar de delegarla a cada subcomando de SST.
- El modificador se aplica al resultado antes de las redirecciones, de modo que `notsh show lan interfaces --csv > ethernet.csv` genera un archivo CSV válido.
- Unifica la conversión en comandos de SST, builtins del shell y procesos externos, incluidas consultas `notsh` sin exportador particular.
- Elimina el rechazo «--csv no está disponible para este subcomando» en rutas de red que ofrecen una consulta válida.
- Evita convertir pantallas interactivas de pantalla completa que no producen un informe.
- Se amplían las pruebas Windows de release para verificar el comando de la captura y las redirecciones de `notsh routes`, `sys info`, `echo` y `netcheck`.
