# SST 0.1.10-blue.2 — Descripciones de paquetes Arch en guide

- La ficha de cada paquete Arch presenta su descripción desde el catálogo oficial de Arch Linux, así como versión, repositorio, arquitectura, URL de proyecto, licencias y dependencias cuando estén disponibles.
- La información consultada se conserva en caché para abrir fichas sin conexión.
- Si Arch no proporciona una ficha verificable se indica expresamente, sin inventar una descripción.
- La selección continúa siendo únicamente una aprobación para evaluar una futura adaptación nativa SST; no instala, descarga ejecutables ni habilita WSL.
- Pruebas de regresión para validar descripciones, dependencias y correspondencia de nombres de paquetes.
