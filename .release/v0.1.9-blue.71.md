# SST 0.1.9-blue.71

## Actualizaciones de paquetes y motores

- Adopta el estándar SST-PACKAGE/1 (índice schema 2) con contratos de ejecución para módulos, runtimes, herramientas CLI y entornos.
- Instp separa módulos cargables, intérpretes, herramientas y entornos en directorios independientes y mantiene un registro de instalaciones.
- PowerShell deja de simular cmdlets: SDK oficial 7.5.13 mediante System.Management.Automation y runspace .NET alojado en SST.
- PowerShell interpreta archivos .ps1 y tuberías de objetos; no ejecuta powershell.exe ni pwsh.exe.
- El paquete SST-PowerShell-win-x64.zip se distribuye por separado para instalarse con instp install powershell.
- Nwash enruta extensiones de script según los intérpretes declarados por los paquetes instalados.
- Mantiene el comando original ps de SST; el motor PowerShell usa psh, powershell y psmodule.
- Arch Linux se registra como entorno WSL2 explícito, con entrada arch COMANDO y sin destruir la distribución al retirar SST.
- Conserva las correcciones de seguridad, consola y presentación de Blue.70.

## Limitaciones comprobables

- Arch requiere WSL2 disponible y autorización explícita para instalar la distribución oficial.
- La integración de PowerShell debe superar la regresión de ejecución .ps1 en Windows antes de considerarse lista para producción.
- Los módulos nativos .NET no se descargan ni se activan automáticamente; requieren instalación con instp y reinicio de SST.
