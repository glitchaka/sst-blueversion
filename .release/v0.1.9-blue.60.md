# Shell Shock Tool 0.1.9-blue.60

## Recuperación sin una consola SST funcional
- El instalador oficial reconoce una instalación existente cuando se abre desde la misma carpeta que `sst.exe` y activa el modo de reparación sin ejecutar la consola averiada.
- La reparación extrae el paquete en una carpeta temporal aislada, conserva el ejecutable anterior y sustituye solamente SST y su actualizador.
- Los datos del usuario, paquetes instalados, preferencias, imágenes de fondo y logo se conservan sin sobrescrituras.
- Si Windows rechaza iniciar el SST reparado, se restaura la versión anterior y el instalador informa del error. No se desactivan ni eluden protecciones de Windows.

## Actualizaciones más seguras
- Se sustituye `ReplaceFileW` por un intercambio de archivos en el mismo volumen, con restauración ante fallo. El archivo nuevo no hereda ACL ni flujos NTFS del viejo.
- Se conserva una copia recuperable del ejecutable anterior y se mantiene el control de integridad SHA-256.
- La validación de Windows comprueba que los flujos NTFS del ejecutable antiguo no contaminan el nuevo.
- El instalador tiene una prueba independiente que repara una instalación inaccesible, comprueba el respaldo y verifica que los datos del usuario se mantienen.
