# Shell Shock Tool 0.1.9-blue.42

## NOTSH — HTTP.sys nativo
- `notsh http show iplisten` consulta con `HttpQueryServiceConfiguration` las direcciones IP limitadas por la configuración del servicio HTTP de Windows.
- `notsh http show urlacl` enumera las reservas de URL mediante la API HTTP Server, sin imprimir descriptores SDDL ni credenciales.
- El parser valida límites y tamaños de buffer para IPv4, IPv6 y cadenas UTF-16 devueltas por la API.
- Se amplían las pruebas nativas de Windows: se comprueba que ambas consultas regresen a Nwash y que no se ejecute `netsh.exe`.

## Mejoras que conserva de blue.41
- Informes de la consola SST con libcaca-rs, estado semántico y etiquetas legibles.
- Diagnóstico WLAN, LAN/Dot3, IPv4/IPv6, WinHTTP, Winsock y Windows Defender Firewall mediante API nativas.
- Actualizador independiente y manifiestos verificables con SHA-256.
- SQLite actualizado con comprobaciones RustSec.

## Alcance
Las reservas URL y la lista IPListen no indican si un servicio está escuchando en un puerto. Notsh aún carece de equivalentes nativos para algunas opciones avanzadas de Netsh, incluidas modificaciones de HTTP.sys, certificados SSL, reglas de firewall, reparación Winsock y controles ETW. No se inventan respuestas para las funciones no disponibles.
