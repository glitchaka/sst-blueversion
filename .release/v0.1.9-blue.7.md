# SST 0.1.9-blue.7

- Guide deja de llevar áreas, comandos, aliases y resúmenes hardcodeados dentro de `sst.exe`: todo el catálogo se carga desde `adm-toolbox/tutorials/guide-index.json`.
- Si el repositorio de Guide no responde o el índice remoto es inválido, `guide` no muestra un catálogo local obsoleto; devuelve únicamente una línea vacía.
- Guide pasa a ser event-driven: deja de limpiar y redibujar toda la pantalla periódicamente cuando no hay interacción.
- El índice de búsqueda se construye una vez por invocación y los manuales/documentos procesados quedan cacheados en memoria, evitando descargas, extracción y word-wrap repetidos por frame.
- El documento `Arch / Portabilidad` pasa al repositorio de tutoriales y se referencia desde el índice remoto como cualquier otra entrada de Guide.
- Office deja de aparecer como categoría independiente en Guide y queda agrupado dentro de Herramientas, coherente con `tools` como framework general por producto/proveedor.
- `tools` deja de presentarse como una utilidad específica de Office y adopta explícitamente el modelo `tools <producto> <acción> [opciones]`.
- El updater pasa a ejecutarse automáticamente al arrancar SST: aplica primero cualquier actualización ya preparada y, si no existe una pendiente, consulta el canal, descarga/verifica una versión nueva, realiza el handoff seguro y relanza SST antes de abrir la sesión normal.
- Si la comprobación del canal falla por red o servidor, SST continúa iniciándose normalmente.
- Mantiene el updater transaccional introducido en 0.1.9-blue.6 para preservar y restaurar el ejecutable activo ante fallos de sustitución.
