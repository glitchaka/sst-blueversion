# Shell Shock Tool 0.1.9-blue.54

## Descargas visibles de INSTP y SST
- Durante `instp upgrade sst`, muestra una barra de progreso actualizada con los bytes reales descargados, porcentaje, tasa de transferencia y tiempo restante cuando el manifiesto indica el tamaño.
- Las descargas de paquetes de `instp install` y `instp upgrade` emplean el mismo medidor; los recursos de GitHub Releases utilizan el tamaño publicado por GitHub.
- Si el tamaño remoto es desconocido, el progreso muestra los bytes recibidos y la velocidad sin inventar porcentaje ni tiempo restante.
- El medidor sólo se activa en sesiones interactivas; stdout de scripts sigue libre de códigos de control.
- El ejecutable sólo se marca como descargado tras verificar el SHA-256 y el tamaño.

## Presentación
- Se eliminó el marco/adorno ASCII del encabezado de informes.
- Se retiró el cambio general del compositor gráfico Slint introducido en desarrollo: los comandos recuperan el dibujado normal de la consola.
- Continúan las consultas y exportaciones NOTSH LAN/WLAN corregidas en el código fuente anterior.

## Validación
- Compilación Windows, prueba real NOTSH LAN/WLAN CSV, regresión del actualizador independiente, pruebas Rust, inspección de manifiesto y SHA-256 antes de distribuir.
- La consulta de enlace cableado no debe confundirse con una autorización NAC confirmada.
