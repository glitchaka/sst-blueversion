# Shell Shock Tool 0.1.7-blue.5

Corte de desarrollo de la rama blue centrado en la interfaz Slint, mensajería LAN,
endurecimiento de seguridad y reconstrucción del intérprete Nwash/Bash.

## Cambios principales

- Migra la interfaz gráfica a Slint 1.18.1 con renderer FemtoVG/OpenGL.
- Amplía `net monitor` con mensajería LAN, comandos internos, salas y mensajes privados cifrados.
- Añade detección de conflictos IPv4 mediante observación ARP con `net conflicts`.
- Refuerza el triage de seguridad, aprendizaje local, diagnóstico de memoria y análisis bajo demanda.
- Amplía y corrige el intérprete Nwash: control de flujo, arrays, namerefs, expansiones,
  quoting, aritmética, subshells, jobs, coprocesos, pipelines y sustituciones.
- Endurece la ejecución de utilidades nativas de Windows para resolverlas desde System32,
  evitando búsquedas relativas desde el directorio de trabajo.
- Evita exponer credenciales HTTP de proveedores e inteligencia en la línea de comandos
  de `curl.exe`; los secretos se entregan mediante stdin.
- Añade regresiones unitarias para cadenas `if/elif/else` y el contrato básico usado por el tour.

## Estado de validación

Los cambios de este corte se preparan sin ejecutar compilación ni suite de pruebas por parte
del asistente. La validación de build y comportamiento se realiza en el flujo local del proyecto
cuando el usuario la solicita.
