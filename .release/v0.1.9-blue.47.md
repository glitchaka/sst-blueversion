# Shell Shock Tool 0.1.9-blue.47

## Presentación de información de SST
- La capa visual de informes recibe el ancho efectivo de la terminal y ajusta las líneas antes de enviarlas al renderizador nativo. Los textos largos y notas de versiones mantienen palabras completas e indentación legible.
- Encabezados compactos dibujados con libcaca-rs; el tamaño se limita al espacio disponible, sin convertir toda la pantalla en un marco.
- Separación visible de etiquetas, valores, advertencias, errores y estados de conexión; se evita clasificar DESCONECTADO como CONECTADO.
- Se añade un fondo de lectura semitransparente detrás de las líneas con texto, sin reemplazar la imagen o configuración de fondo del usuario.
- La tarjeta de inicio `fetch` utiliza dimensiones compactas y límites de longitud acordes a la ventana.
- `top` emplea un tablero de procesos con encabezados y filas contrastadas, métricas alineadas y actualización de CPU basada en un muestreador persistente.
- Se conservan la salida original de comandos de scripts, tuberías, redirecciones, JSON, CSV, XML y programas que ya emiten ANSI.

## NOTSH y gestor de paquetes
- Se mantienen las consultas nativas mediante Windows API implementadas previamente, con las funciones que aún no existen señaladas explícitamente.
- `instp sst`, `instp check sst` e `instp upgrade sst` gestionan la versión y actualización de SST; `update` ya no se registra como comando independiente.

## Validación
- La regresión en Windows comprueba el actualizador independiente, la ruta de instalación con instp y las consultas nativas.
- Los informes incluyen pruebas de wrapping, ancho pequeño, campos, estados y preservación de formatos para uso automático.

## Alcance
No implica paridad completa de Notsh con Netsh. La nueva capa visual no sustituye el motor de terminal Slint/VT100 ni falsea datos del sistema.
