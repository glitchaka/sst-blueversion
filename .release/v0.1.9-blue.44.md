# Shell Shock Tool 0.1.9-blue.44

## NOTSH: sesiones ETW nativas
- `notsh trace show sessions` consulta sesiones existentes mediante `QueryAllTracesW` de Windows.
- Muestra nombre, búferes escritos y contadores de eventos perdidos cuando Windows permite consultar esos datos.
- Mantiene `notsh trace HOST` como diagnóstico de ruta; no lo confunde con el control de sesiones.
- No invoca `netsh.exe`, `logman.exe`, CMD ni PowerShell para consultar las sesiones ETW.
- Añade comprobaciones de ABI y límites de lectura de estructuras y cadenas UTF-16.
- Amplía la regresión nativa de Windows para comprobar que Notsh devuelve el control a la consola.

## Funciones heredadas de blue.42
- `notsh http show iplisten` y `notsh http show urlacl`, consultas de HTTP.sys por HTTP Server API.
- WLAN, LAN y Dot3, IPv4/IPv6, WinHTTP, Winsock2 y perfiles del firewall mediante API de Windows.
- Informes visuales mejorados con libcaca-rs, sin modificar la salida tabular para scripts.
- Actualizador independiente y canales con manifiestos SHA-256 validados.

## Límites
Enumerar sesiones no supone iniciar, detener o registrar trazas, y la visibilidad depende de los permisos del usuario. Permanecen pendientes las operaciones avanzadas de administración de certificados, firewall, Winsock y trazas.
