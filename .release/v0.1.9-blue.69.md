# Shell Shock Tool 0.1.9-blue.69

## Seguridad: contraseñas de dominio

**Cambio obligatorio de sintaxis:** -p y --password ya no reciben un valor.

- sys domain join -d DOMINIO -u CUENTA [-ou RUTA_OU] -p
- sys domain leave -u CUENTA -p

SST solicita la contraseña por una ventana de credenciales de Windows (CredUI). Si la operación necesita privilegios elevados, primero solicita UAC; después recoge la contraseña dentro del proceso autorizado.

Las contraseñas **no se introducen en la línea de comandos**, no se escriben en el historial y no se incluyen en el comando del proceso hijo. La contraseña pasa a NetJoinDomain/NetUnjoinDomain como buffer UTF-16 temporal, que se sobrescribe tras utilizarlo.

Las entradas antiguas -p CONTRASEÑA o --password CONTRASEÑA se rechazan antes de que la shell pueda imprimirlas en modo verbose. En la consola integrada, después de escribir -p no se aceptan caracteres: pulsa Enter para abrir la entrada protegida.

El inicio depura del historial de SST las antiguas líneas sys domain join/leave que contienen -p/--password. Si una contraseña se expuso en una compilación anterior, debe rotarse: la depuración local no elimina copias de seguridad, capturas ni registros externos.

## Calidad y compatibilidad

- Pruebas unitarias del análisis de argumentos y limpieza de historial.
- Prueba de regresión Windows que rechaza valores sensibles inline sin mostrarlos y comprueba que el payload UAC carece de contraseña.
- Se conserva la ruta NetAPI nativa de Windows, sin PowerShell ni wrappers netdom.
- Se incluyen los cambios de Blue.68, entre ellos el arranque con renderización Slint por software.

**Alcance:** Esta corrección se refiere a sys domain join/leave. No implica que otras utilidades que acepten contraseñas en argumentos, como Autologon, estén protegidas por este mismo cambio.
