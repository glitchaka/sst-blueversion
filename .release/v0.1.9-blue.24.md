# Shell Shock Tool 0.1.9-blue.24

- La isla superior de SST identifica siempre el token de la sesión: USUARIO, LIMITADO, ADMIN, SYSTEM o TRUSTED.
- USUARIO y LIMITADO aparecen en un indicador neutro; sólo ADMIN, SYSTEM y TRUSTED se destacan como sesiones elevadas.
- El título nativo de la ventana y del selector de tareas también identifica el nivel del token.
- El indicador permanece visible en ventanas estrechas, sin superponerse con las métricas de CPU/RAM.
- El nivel se obtiene del token real del proceso, no del parámetro usado para lanzar la ventana.
- El disparador de publicación admite todas las próximas versiones blue en vez de quedar fijado a blue.23.

La escalada sudo no cambia. El comportamiento en Windows debe comprobarse en la compilación de esta versión.
